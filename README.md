# GreedySnake · 贪吃蛇

原生 HTML / CSS / JavaScript 贪吃蛇，无框架、无运行依赖、无外部网络资源。

## 运行

下载或克隆整个仓库，用现代浏览器直接打开 `demo.html` 即可。请保留 `assets/` 目录，它包含页面所需的样式和脚本。

也可以在仓库目录启动静态服务，例如安装 Python 后运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/demo.html`。

## 目录结构

```text
GreedySnake/
├── demo.html            # 页面结构与入口
├── assets/
│   ├── style.css        # 掌机风格与响应式布局
│   ├── game.js          # 纯游戏逻辑，不依赖 DOM
│   └── app.js           # Canvas 绘制、操作、计时和本地存储
├── tests/
│   └── game.test.cjs    # Node.js 核心逻辑测试
├── .editorconfig       # 编辑器缩进和编码约定
├── .gitattributes      # 统一文本换行
└── .gitignore          # 排除截图、依赖和系统临时文件
```

`game.js` 同时供浏览器和 Node.js 测试使用；修改规则时不需要改页面交互。保持普通脚本加载，无需构建，也能通过本地文件直接运行。

## 操作

- 方向键或 WASD：移动；待开始时按方向键也可开始。
- 空格：开始、暂停或继续。
- Enter：待开始或结束时开始新一局。
- 手机：在棋盘上滑动，或使用页面方向按钮。
- 切换标签页或窗口失焦时自动暂停，返回后手动继续。

每个果实加 10 分，蛇身增长一格，速度逐渐提升。碰到墙壁或自身结束，填满棋盘获胜。最高分保存在当前浏览器；浏览器禁止本地存储时仍可正常游玩。

## 验证核心逻辑

安装 Node.js 18 或更新版本后，在仓库目录运行（无需安装 npm 包）：

```sh
node --test tests/game.test.cjs
```

测试覆盖食物位置、增长、墙壁和自身碰撞、快速转向、尾格移动、暂停、重新开始及填满棋盘。

已在桌面 Microsoft Edge 中验证本地文件与 HTTP 两种打开方式，并检查键盘操作、暂停与继续、重开、最高分保存、存储禁用降级和不同屏幕宽度。手机操作通过窄屏和指针手势模拟验证，尚未进行手机真机测试。
